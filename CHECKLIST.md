# v1 Pre-Submission Checklist

## Facts and fit

- [ ] Track, Profile, Emphasis, confidence, fit, and gaps were inspected.
- [ ] Low fit or material ambiguity has an explicit recorded user override.
- [ ] Every claim is linked to canonical facts; no pending or unlinked claim remains.
- [ ] Historical titles, dates, metrics, uncertainty, and language levels are unchanged.
- [ ] Direct SaaS/software Sales is not implied unless independently verified later.

## Review and artifacts

- [ ] The user reviewed and approved this exact Markdown version, or explicit fast mode
      was used.
- [ ] HTML and PDF were generated by the v1 engine from the approved source.
- [ ] Recruiter-facing filename uses the normalized target role without invented
      seniority.
- [ ] The PDF, HTML, Markdown, claim manifest, visual evidence, and decision record are
      versioned and referenced in SQLite.

## Ready contract

- [ ] Content validation passed.
- [ ] Profile/Fit validation passed.
- [ ] Structure and section-order validation passed.
- [ ] Page-count and PDF integrity validation passed.
- [ ] ATS text extraction and source comparison passed.
- [ ] Email, phone, LinkedIn, and relevant GitHub links passed.
- [ ] Visual overflow/clipping review passed.
- [ ] RTL/LTR and mixed-direction checks passed where applicable.
- [ ] Filename and metadata validation passed.

## Tracking

- [ ] `cv ready <application-id>` passes.
- [ ] Next action and date are recorded when relevant.
- [ ] If submitted, status is `applied` and the exact PDF version has an immutable
      submission record.
- [ ] `cv reconcile` passes.
