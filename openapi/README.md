# Generated API contract

Two generated files, both committed, both regenerated deliberately.

| File | Generated by | Checked by |
| --- | --- | --- |
| `openapi.json` | `python openapi/generate_openapi.py` | `tests/test_api_contract.py` |
| `types.ts` | `npm ci && npm run generate` | `git diff --exit-code` after that run |

They are committed rather than built on demand so that a change to a request or
response schema shows up as a reviewable diff, in the same way the frozen SQLite
fingerprint does. A moved file is fine; a moved file nobody noticed is not.

This directory holds no frontend. React, Vite, and Tailwind arrive in M4;
`openapi-typescript` is the only dependency here.

Regenerating after an API change:

```bash
python openapi/generate_openapi.py
cd openapi && npm ci && npm run generate
```

Then state the entry-level diff in the commit message.
