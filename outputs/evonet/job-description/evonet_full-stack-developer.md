## Job Description

About EVONET

EVONET is a software development studio that takes clients from a rough idea to a shipped product - web systems, mobile apps, and the UX/UI design in between. We build custom CRMs, internal portals, reporting dashboards, and iOS/Android apps for small and medium businesses that need real software but don't have an in house dev team.

We're small, senior, and hands on. Every project gets a free specification session before a line of code is written, a security and load audit before launch, and a full year of hosting and maintenance after. You'd be joining a team that ships real products and stands behind them.

About the role

We're looking for a Full Stack Developer to build across web and mobile alongside our team. You'll take features from spec to production - writing clean front end code, building reliable back end services, and seeing your work run in real businesses. You'll have real responsibility for what you build, with senior developers around you to learn from and lean on.

What you'll do

- Build features across the full stack - front end interfaces and back end services and APIs
- Turn designs and specifications into working, maintainable software
- Design and integrate RESTful APIs and work with relational databases
- Contribute to web systems and mobile apps depending on the project
- Write clean, tested code and take part in code reviews
- Help with pre-launch testing so what we ship is stable and secure
- Work with our designers and clients to make sure features solve the actual problem

What you bring

- 2+ years building production web applications
- Solid skills in a modern JavaScript/TypeScript stack (e.g. React on the front end, Node.js on the back end)
- Experience with RESTful APIs and relational databases (PostgreSQL / MySQL)
- Good debugging skills and attention to code quality
- The ability to own a feature end to end and communicate clearly about it
- Willingness to learn new tools, stacks, and parts of the product

Nice to Have

- Mobile development experience (React Native, Flutter, or native iOS/Android)
- Familiarity with hosting, deployments, and basic DevOps
- Experience with automated testing
- A degree in computer science or equivalent hands-on experience

Why EVONET

- Real responsibility from the start
- A small senior team you'll actually learn from
- Direct client contact and the satisfaction of seeing your work in production
- A studio with a genuine quality bar: spec up front, testing before launch, support after
