# Job Description — Unit · Internal Tools Engineer

## Company
Unit — embedded finance platform. ~100 customers (Wix, Honeybook, Relay). $40B+ processed annually, 12M+ API calls/day. $160M+ raised (Insight, Accel).

## Role
Junior Engineer, Internal Tools team. Part-time with potential to go full-time.

## Responsibilities
- Build and maintain internal dashboards, applications, workflows, automations (Retool + other tooling)
- Develop scripts, queries, lightweight technical solutions for business/operational needs
- Partner with stakeholders to gather requirements and deliver practical solutions
- Proactively identify process improvement opportunities
- Use AI-based tools (Cursor, Base44, etc.) to accelerate development
- Support ongoing maintenance of internal tools across the org

## Requirements
- CS / Software Engineering degree (pursuing or completed)
- 1-2 years experience with internal tools, automations, or operational systems (advantage)
- Strong analytical and problem-solving skills
- Python, JavaScript, or similar — solid coding ability
- Familiarity with relational databases and SQL
- Git, testing, debugging practices
- Comfort with AI-assisted tools (Cursor, Base44, similar)
- Builder mindset: spot opportunities, ship working solutions
- Excellent written and spoken English
