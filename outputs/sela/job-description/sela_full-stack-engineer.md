# Job Description — Sela · Full Stack Engineer

## Company
Sela

## Role
Full Stack Engineer

## Summary
Full Stack Developer role with balanced frontend/backend split (slight backend inclination). Backend uses Java; frontend uses React. AI technologies and AI Agents are part of daily development workflow.

## Responsibilities
- Develop complex web-based Full Stack systems
- Backend development using Java
- Frontend development using React
- Work with AI technologies and AI Agents as part of the development process
- Collaborate within a development team in a highly technological environment

## Requirements
- At least 1 year of software development experience
- Experience working with React and Java
- Interest in or experience with AI / AI Agents
- Ability to work collaboratively in a complex technological environment

## Key ATS Keywords
Full Stack, React, Java, AI Agents, AI technologies, web-based systems, collaborative, complex technological environment

## Notes
Java is a hard requirement on paper but role description is broad. Python backend experience + React + AI integrations cover most of the role. Java is the only gap.
