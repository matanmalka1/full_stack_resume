# CV Review Checklist

Run before sending any application.

## Content
- [ ] No invented technologies or tools
- [ ] No inflated seniority (not "Senior" or "Architect" unless role matches)
- [ ] All metrics and dates match `base/cv_base.md`
- [ ] Job keywords appear naturally in Profile and bullets
- [ ] Backend bullets are specific and strong (not generic)
- [ ] No buzzwords: passionate, ninja, rockstar, dynamic, results-driven

## Format
- [ ] Fits one page
- [ ] Notes saved separately as `.notes.md` (not inside the CV)
- [ ] HTML generated from `.md`
- [ ] PDF exported from `.html` (not from `.md`)

## Details
- [ ] Phone number correct
- [ ] Email correct
- [ ] GitHub link correct
- [ ] LinkedIn link correct
- [ ] File name matches pattern: `cv_<company>_<role>.pdf`

## Tracking
- [ ] Job description saved to `jobs/<company>_<role>.md`
- [ ] Row added to `jobs/status.csv`
